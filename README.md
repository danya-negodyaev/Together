# Together: кино вдвоём на расстоянии

Твой личный сайт для совместного просмотра. Он работает у тебя на компьютере, а не в чужом облаке.

- Плеер синхронный: пауза, перемотка и запуск срабатывают сразу у всех. Небольшой рассинхрон сайт сам выравнивает за доли секунды.
- Рядом чат и реакции 😂 😱 ❤️ 🔥 👍 😭. Реакции всплывают прямо поверх фильма.
- Есть два режима:
  - **«С компьютера»**: фильм идёт с твоего ПК, другу ничего скачивать не нужно.
  - **«Свой файл»**: у каждого своя копия фильма, по сети идут только команды. Хорошо работает даже на медленном интернете.
- Работает на iPhone: видео на весь экран, когда телефон повёрнут боком, чат поверх, сообщения всплывают.
- Можно подключить субтитры `.srt` / `.vtt`, в том числе русские в кодировке Windows-1251.
- Если у кого-то видео не успевает подгрузиться, сайт ставит паузу всем и ждёт.

---

## 1. Первый запуск (на твоём компьютере)

1. Установи **Node.js** версии LTS с сайта <https://nodejs.org>. Подойдут настройки по умолчанию. Это нужно сделать один раз.
2. Положи фильмы в папку `movies`. Лучше всего подходит MP4. Можно указать и свою папку, об этом ниже, в разделе «Настройки».
3. Дважды щёлкни `start.bat`.
   - При первом запуске Windows спросит про брандмауэр. Нажми **«Разрешить доступ»**, иначе друг не подключится.
   - Сайт сам откроется в браузере. Впиши своё имя.
4. В чёрном окне сервера будут **пароль комнаты** и ссылки. Не закрывай это окно, пока смотрите фильм.

## 2. Как подключить друга (iPhone)

Другу нужно попасть на твой компьютер через интернет. Есть два способа.

### Способ А: Tailscale (проще и безопаснее)

Tailscale — бесплатная программа, которая соединяет ваши устройства в одну частную сеть.
Белый IP и настройка роутера не нужны, а весь трафик шифруется.

1. **На компьютере** установи Tailscale с <https://tailscale.com/download> и войди (через Google, Microsoft или GitHub).
2. **Друг** ставит Tailscale из App Store и входит в **свой** аккаунт.
3. Поделись с ним своим компьютером. Открой <https://login.tailscale.com/admin/machines>, у своего компьютера нажми **«…» → Share** и отправь другу ссылку-приглашение. Он её примет.
4. Перезапусти `start.bat`. В окне появится строка **«Через Tailscale»** и готовая **ссылка для друга**, в которую уже вписан пароль. Отправь её другу в мессенджере.
5. У друга в приложении Tailscale должен быть включён переключатель (VPN). Ссылку он открывает в Safari.

> В России Tailscale работает не у всех: иногда приложение не скачивается или не может соединиться. Тогда используй способ Б.

### Способ Б: проброс порта на роутере

Этот способ работает, только если у тебя **«белый» (публичный) IP**.

1. Узнай внешний IP на сайте <https://2ip.ru>. Потом найди в настройках роутера адрес WAN / «Интернет». Если адреса совпадают, IP белый. Если нет, провайдер выдаёт серый IP. Белый обычно можно подключить у провайдера отдельной услугой.
2. В настройках роутера найди раздел **«Перенаправление портов»** (Port Forwarding / Виртуальные серверы). Добавь правило: протокол TCP, внешний порт `8765` → IP компьютера (он показан в строке «Домашняя сеть»), порт `8765`.
3. Друг открывает `http://ТВОЙ-ВНЕШНИЙ-IP:8765/?k=ПАРОЛЬ`.

Минус способа: соединение не шифруется. Пароль защищает вход, но Tailscale всё равно надёжнее.

### Если друг подключается к твоему Wi-Fi

Подойдёт адрес из строки **«Домашняя сеть»**.

## 3. Режимы

### «С компьютера»

Фильм раздаётся с твоего ПК. В строке под плеером есть **«битрейт ≈ … Мбит/с»**: это скорость, с которой фильм нужно передавать.
Твоя **исходящая** скорость должна быть заметно выше этой цифры. Обычно фильму 720p нужно 2–5 Мбит/с, а 1080p — 5–10 Мбит/с.
Если у друга видео не успевает грузиться, сайт сам поставит паузу всем и подождёт.
С каждой новой паузой он ждёт дольше, чтобы остановок было меньше.

Субтитры кладутся рядом с фильмом под тем же именем: `Фильм.mp4` + `Фильм.srt` (или `Фильм.ru.srt`, `Фильм.en.srt`).
Включаются кнопкой **CC** в плеере. У каждого зрителя субтитры свои.

### «Свой файл»

Каждый открывает у себя одинаковый фильм. По сети идут только команды, поэтому скорость интернета почти не важна.

- **На iPhone** фильм сначала нужно сохранить в приложение **«Файлы»**. Его можно скачать по кнопке ⬇ в списке фильмов (окно «Выбрать фильм» в режиме «С компьютера»), из Telegram или из облака.
  Потом нажми **«Выбрать файл» → «Обзор»** и выбери фильм. Не выбирай из «Фото»: оттуда iPhone пережмёт видео.
- Сайт сравнит длительность файлов и предупредит, если у вас разные версии фильма.
- Свои субтитры подключаются кнопкой **«Субтитры»**.

## 4. Советы для iPhone

- **Добавь сайт на экран «Домой»** (в Safari: «Поделиться» → «На экран „Домой“»). Он будет открываться как приложение, без панелей Safari.
- **Поверни телефон боком**: фильм развернётся на весь экран. Чат открывается кнопкой 💬, а новые сообщения всплывают поверх фильма.
- Если появилась кнопка **«Нажми, чтобы присоединиться»**, просто нажми её. iPhone не разрешает сайтам включать звук без касания, поэтому так бывает один раз.
- Громкость регулируется кнопками телефона.
- Если друг свернёт Safari или ему позвонят, пауза встанет у всех.

## 5. Горячие клавиши (на компьютере)

| Клавиша | Действие |
|---|---|
| Пробел | пауза / воспроизведение |
| ← / → | на 10 секунд назад / вперёд |
| F | во весь экран (чат остаётся сбоку) |
| M | выключить / включить звук |
| C | переключить субтитры |
| Enter | перейти в чат |

## 6. Форматы видео

- **Надёжнее всего MP4: видео H.264 и звук AAC.** Такой файл откроется и на Windows, и на iPhone.
- **MKV** iPhone не открывает. Видео **HEVC/H.265** может не открыться в Chrome на Windows, а со звуком **AC3/DTS** браузеры часто показывают фильм без звука.
- MKV с видео H.264 можно быстро и без потери качества перепаковать в MP4. Для этого нужен [ffmpeg](https://ffmpeg.org) (или программа HandBrake):

  ```
  ffmpeg -i "фильм.mkv" -map 0:v:0 -map 0:a:0 -c:v copy -c:a aac -b:a 192k -movflags +faststart "фильм.mp4"
  ```

## 7. Настройки (`config.json`)

Файл появляется после первого запуска:

```json
{
  "port": 8765,           // порт сервера
  "password": "abcde-fghjk", // пароль комнаты (регистр не важен)
  "moviesDir": "movies",  // папка с фильмами, можно полный путь: "D:\\Фильмы"
  "openBrowser": true     // открывать сайт при запуске
}
```

Комментарии выше даны для пояснения, в самом файле их нет. После изменений перезапусти `start.bat`.
Если сменить пароль, всем придётся войти заново.

## 8. Если что-то не работает

- **Друг не может открыть ссылку.** Проверь, что окно сервера открыто, а Tailscale включён у обоих. Если не помогло, запусти `open-firewall.bat` правой кнопкой → «Запуск от имени администратора». Он разрешит подключения в брандмауэре Windows.
- **«Порт уже занят».** Сервер уже запущен в другом окне, либо порт занят другой программой. Поменяй `port` в `config.json`.
- **«Видео не открывается».** Скорее всего, дело в формате файла, см. раздел 6.
- **В режиме «С компьютера» часто встаёт пауза «Ждём…».** Твоей исходящей скорости не хватает на этот фильм. Возьми файл поменьше или переключитесь на «Свой файл».
  Если вы подключены через Tailscale, проверь в командной строке: `tailscale ping ИМЯ-ТЕЛЕФОНА-ДРУГА`. Если в ответе есть `via DERP`, соединение идёт через ретранслятор, а не напрямую, и скорость заметно ниже.
- **Чат и позиция фильма** сохраняются в `data/state.json`. Удали этот файл, чтобы очистить историю.

## Безопасность

- Без пароля на сайт не попасть. После 10 неверных попыток адрес блокируется на 15 минут.
- Сервер отдаёт только видео и субтитры из папки с фильмами и ничего больше с твоего компьютера.
- Не выкладывай ссылку с паролем в открытый доступ. Чтобы получить новый пароль, удали строку `"password"` из `config.json`: при следующем запуске он придумается сам.
